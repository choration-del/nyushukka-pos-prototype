# Nyushukka代替POS・原画像参照の試作 v0.2.1

商品登録、販売、現金仕入、棚卸を試し、父親・クライアントから旧ソフトとの差を聞くための試作です。実会計用の完成版ではありません。原画像との対応と未確認事項は、同梱の「原画像との対応・未確認事項.md」にまとめています。

## ダウンロード

[最新版をダウンロード](https://github.com/choration-del/nyushukka-pos-prototype/releases/latest)

リリースのAssetsにある **nyushukka-pos-windows-0.2.1.zip** を受け取ってください。Source codeのZIPには実行環境が入っていません。共有版は元スクショ・店舗資料を含みません。

## 起動と終了

ZIPをすべて展開して、`起動.bat`をダブルクリックしてください。ブラウザーが開かない場合は `http://127.0.0.1:4318` を開きます。終了は、起動時の黒いウィンドウでCtrl+Cです。

Windows 10/11の64ビットPCと通常のブラウザーが必要です。Node.js 24.21.0の実行環境を同梱しました。別途インストールは不要です。「起動エラーと更新手順.md」も確認してください。基本操作にネット接続は不要で、外部サービスは呼び出しません。同一フォルダーの二重起動は既存の画面を開きます。別フォルダーの同時起動は止めます。複数タブでの同時入力には対応していません。

原画面の位置関係を保つためメイン画面は約1360pxの幅を使います。狭いウィンドウでは横スクロールしてください。日常使用するPCの解像度と拡大率は未確認です。

## 最初に試す

テスト商品：バーコード500、ショートカット1、販売100円、仕入50円、内税10%。配置確認商品：バーコード501、販売120円、仕入60円。試用顧客、テスト商店、開発確認用の取引・仮伝票も入っています。すべて架空の試作データです。

1. 販売：500→Enter。100円・内税9円を確認。入力キーが空の状態でEnter→預かり200円→記録。お釣り100円。
2. 同じ商品を続けて入力：既定では同じ商品・単価を一行にまとめ、数量を増やします。「各種設定」のメイン画面で切り替えられます。
3. 仕入：F8→500→Enter→数量を入力→OK→決定→記録。仕入先がない商品では、新規登録または既存から選択を求めます。
4. 仕入の記録後は明細が残ります。もう一度決定しても二重記録しません。次の商品入力から新伝票を始めます。
5. 棚卸：F10→全商品準備で「はい」→500→Enter→実数量→OK→決定→記録。在庫残高は更新しません。
6. 登録：商品リスト／仕入先リスト／顧客管理から新規登録・項目変更。商品登録後の「はい＝続けて入力、いいえ＝同名別価格、キャンセル＝終了」も試せます。
7. 点検：取引を選ぶと、下に明細と合計が出ます。番号・分類・担当者・期間で絞れます。
8. 未確認モード：カード・掛売等でも商品入力は可能です。決定では「仮伝票」として別保存し、売上・残高・在庫には反映しません。ツールメニューの仮伝票一覧で確認できます。

## v0.1から変更したこと

- 原画像に合わせた黒い表示領域、水色文字、表示列、価格欄、二段のモードボタン順、右下の決定ボタン。
- 商品・顧客・仕入先の縦型フォーム、税・性別のラジオ、値引・ポイントのチェック、郵便・電話・FAXの分割欄。
- 商品リスト・仕入先リスト・商品管理・顧客管理を別画面へ分離。点検は履歴と明細を一緒に表示。
- 精算の三列の項目配置を確認用に追加。未確認の金額は「未確認」と表示し、締めを実行しない。
- 同商品合算と業務別の数量入力設定、0円商品の価格入力、入金種別と入出金の摘要履歴。
- 仕入先登録誘導、記録済み仕入明細の保持、仮伝票の別保存、直前データの退避。
- 連続商品入力を順番に処理。保存中はフォームをロック。モード切替では未保存入力の消去確認。

## 実装済み・仮実装・未実装

| 区分 | 内容 |
|---|---|
| 操作・保存を実装 | 共通画面、主なキー、商品検索、明細選択・数量・増加・削除、商品・顧客・仕入先の保存と編集、設定の一部、バックアップJSON保存、点検の検索・明細表示 |
| 仮の取引記録 | 販売、現金仕入、棚卸、通常入出金。仕入先・顧客・価格・税を取引時点で記録 |
| 仮伝票だけ保存 | カード、商品券、掛売、割販、掛仕入、予約・注文、破棄、移動入庫、移動出庫。正式な取引へ変換しない |
| 観察用の画面 | 商品管理の期間販売数・仕入数・仕入額、精算の一部全期間合計。旧ソフトと計算結果を照合する前の表示 |
| 未実装 | 正式な精算・締め・履歴、掛売回収・債権残高、返品・確定後訂正、正式な帳票・プリンター・ドロワー等、旧データ移行、ポイント・顧客値引、マクロ、部門・担当者マスタ、カスタムキー、復元画面、旧ツールバーの完全一致 |

税は明細単位の切捨てによる仮計算です。100円内税10%→9円を再現していますが、外税・仕入・複数明細の旧算式は未確定です。棚卸の実数は保存するだけで、在庫残高や差異を更新しません。値引は選択明細の合計から円単位で控除する仮仕様です。客層調査は父親の実運用要件に従って無効です。

試作では価格・金額は円単位の整数、数量も整数です。価格・取引合計は1億円まで、数量は10万までの仮の上限を設けています。小数数量・負数・返品の入力は扱いません。これは旧ソフトから確認した入力範囲ではありません。

画像の設定値は調査時の値です。父親の店舗設定と同じとは断定していません。ツールバーは機能が未確認のアイコンを推測せず、暫定の文字ボタンです。原画像の完全な複製を達成したとは扱いません。

## 保存とバックアップ

このフォルダーの`data/pos.json`が保存先です。保存前の状態を`data/pos.json.bak`に退避します。商品マスタを変更しても過去取引の商品名・価格を変更しません。仮伝票は通常取引と別に保存し、集計に混ぜません。

ツール→バックアップで全データのJSONをダウンロードできます。復元する場合はアプリを終了し、現在のpos.jsonを別名で保管し、バックアップをdata/pos.jsonとしてコピーして再起動してください。pos.json.bakも同じ方法で直前状態の復元に使えます。画面からの復元は未実装です。

入力途中の明細は未保存ですが、他の管理画面へ移動してもメイン画面の入力は保持します。終了・ページ更新で未保存入力があるときには確認を出します。停電・ディスク故障、複数端末、長期運転は未検証です。
